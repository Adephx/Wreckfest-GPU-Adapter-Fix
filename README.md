Supports Wreckfest 1.308438, both 32-bit and 64-bit.

Steam build: 16986367 - published 2 February 2025.

1. Run `Patch.bat`;
2. Enter the full path to the folder containing the game executables;
3. Select `1 - Patch.`;
4. Launch Wreckfest with `-`setup` and select your GPU.

To undo the patch, run the BAT again and select `2 - Restore`.
